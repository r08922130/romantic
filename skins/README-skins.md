# 貓咪造型檔（`.cat`）怎麼畫

每個 `.cat` 檔就是一種貓咪造型。在 `cats.json` 用 `"skin": "檔名（不含 .cat）"` 指定。

## 最快的方法：只換顏色

```
name: tuxedo
base: patches          # 沿用 patches 的所有姿勢
palette:  O=240  S=238  C=240  T=240  A=149b
```

`tuxedo.cat`（黑白貓）、`spots.cat`（白底橘點貓）、`ginger.cat`（全橘虎斑幼貓）都是這樣做出來的。

`patches` 的顏色代號：`O` 身體／背、`S` 條紋（或斑點）、`W` 肚子臉白色、`C` 頭頂和耳朵、`T` 尾巴尖、
`A` 眼睛、`P` 鼻子、`K` 鬍鬚。
小技巧：把 `O` 設成白色、`S` 設成橘色，背上的條紋就會變成橘色斑點（`spots.cat`）。

## 檔案格式

```
name: tabby                      # 名字（可省略，預設為檔名）
base: patches                    # 選填：從別的造型繼承，再覆蓋你寫的部分
size: 22 6                       # 外框寬 x 高（字元）。所有圖案都要畫在框內
palette: O=208 S=130 W=255b      # 顏色代號 = 256 色編號，後面加 b 代表粗體/亮色
eyes: normal=o wide=O happy=^ closed=- wink=^-   # 各種表情的眼睛（2 個字 = 左眼右眼）
hat: 3 1                         # 配件（聖誕帽、蝴蝶結…）戴在頭的哪裡：帽簷左端的 x y

@head                            # 頭（每個姿勢共用）。第一列留空給帽子
|
| {O}/\___/\
|{O}({A}%L{O}${P}.{O}${A}%R{O})  # %L / %R 會被換成左、右眼
| {K}>{O}${P}w{O}${K}<

@pose stand                      # 一個姿勢
@layer 0 1 tail                  # 一層圖案，左上角放在 (x=0, y=1)
|{O} ,
---                              # 「---」= 下一格動畫
|{O},
@layer 0 5 walk                  # walk 層：走路時換格；tail 層：搖尾巴時換格
|...
@layer 12 0 head                 # 把頭放在 (12, 0)
```

### 圖案列的規則

- 每列以 `|` 開頭，`|` 後面的內容原樣保留（前面的空白也算），不需要跳脫反斜線。
- `{X}` 切換顏色，`X` 是 palette 裡的代號（例如 `{O}` 橘色、`{W}` 白色）。
- 空白 `' '` 是透明的，會看到背景。
- `$` 是「不透明的空白」，畫在臉的內部，背景（例如聖誕樹）才不會從臉上透出來。
- 後畫的層會蓋掉先畫的層，所以頭通常放最後。
- 一律畫**面向右邊**，往左走時程式會自動左右鏡像（`/`↔`\`、`(`↔`)` 等）。

### 配件（帽子等）不畫在造型裡

造型只畫**貓本身**。帽子這類東西屬於場景：聖誕節戴聖誕帽、示範場景戴蝴蝶結，
由場景的 `CAT_ACCESSORY` 決定，畫在 `hat:` 標記的位置（帽簷蓋住兩耳之間的 `___`）。
沒寫 `hat:` 的造型就不戴配件；用 `base:` 繼承的造型會沿用父造型的 `hat:`。

### 姿勢一覽

| 姿勢 | 用在 | 沒畫時 |
|---|---|---|
| `stand` | 站、走路 | **必畫** |
| `sit` | 坐、看樹、搖尾巴、最後的驚喜 | **必畫** |
| `sleep` | 穩重貓打盹 | 用 `sit` |
| `run` | 衝刺、跳躍 | 用 `stand` |
| `crouch` | 撲禮物前蹲低 | 用 `sit` |
| `peek` | 躲在禮物後探頭 | 只畫頭 |

### 個性（寫在 `cats.json`）

| personality | 行為 |
|---|---|
| `calm` | 慢慢走、坐著搖尾巴、縮成一團睡、呆呆看樹、被找玩時會慢慢跟過去 |
| `playful` | 衝刺、跳、躲禮物後探頭、撲禮物、去蹭別的貓再跑開 |

## 邊畫邊檢查

```powershell
python main.py --preview-skin tabby                 # 看一個造型的所有姿勢（左右兩個方向），戴聖誕帽
python main.py --preview-skin tabby --scene demo    # 換成示範場景的配件（蝴蝶結）
python main.py --preview-cats                       # 看 cats.json 裡所有貓
```

圖案超出 `size` 外框時，預覽會顯示 `WARNING`。
